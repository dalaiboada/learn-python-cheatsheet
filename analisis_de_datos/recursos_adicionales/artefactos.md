## 🌐 Repositorios y Fuentes de Datasets

Fuentes confiables para encontrar datos abiertos para proyectos de análisis, estadística y Machine Learning.

| Plataforma                                | Tipo de Datos / Enfoque                                                                                                       | Enlace                                                                                |
| :---------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------ |
| **Kaggle**                          | Plataforma con miles de datasets comunitarios, competencias de ML y notebooks interactivos.                                   | [Explorar Kaggle](https://www.kaggle.com/)                                             |
| **Google Cloud (BigQuery)**         | Conjuntos de datos públicos a gran escala listos para consultar mediante SQL en BigQuery.                                    | [Ver Datasets Públicos](https://docs.cloud.google.com/bigquery/public-data?hl=es-419) |
| **UCI Machine Learning Repository** | Repositorio académico clásico con cientos de datasets estándar para benchmarks de clasificación, regresión y clustering. | [Explorar UCI ML](https://archive.ics.uci.edu/)                                        |
| **Amazon Web Services (AWS)**       | Datos abiertos y portal de introducción para trabajar con recursos en la nube de Amazon.                                     | [Portal AWS](https://aws.amazon.com/es/getting-started/?nc1=h_ls)                      |
