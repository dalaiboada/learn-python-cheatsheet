# Análisis de Datos

Este módulo cubre los fundamentos y técnicas esenciales para el análisis de datos utilizando Python, con énfasis en la manipulación, limpieza, transformación de datos y visualización de resultados.

## Fundamentos y filtrado de datos

En esta sección se abordan los conceptos básicos del análisis de datos:

- Estructuras de datos para análisis (Series, DataFrames)
- Operaciones básicas de selección y filtrado
- Filtrado condicional y combinación de condiciones
- Manejo e inserción de columnas
- Funciones de agregación (sum, mean, count, etc.)

## Métodos de agrupación de datos

Esta sección explora las técnicas de agrupación y agregación:

- GroupBy y operaciones de agrupación
- Agrupación múltiple y jerárquica
- Transformaciones y filtros en grupos
- Tablas dinámicas y pivot tables

## Limpieza de datos

En esta sección se aprenden las técnicas para preparar datos de calidad:

- Detección y manejo de valores faltantes
- Identificación y tratamiento de valores duplicados
- Normalización y estandarización de datos
- Detección y manejo de outliers
- Validación de tipos de datos y conversión
- Técnicas de imputación de datos
