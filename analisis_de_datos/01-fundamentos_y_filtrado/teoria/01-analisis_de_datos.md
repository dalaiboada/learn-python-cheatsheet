# Análisis de Datos

> El análisis de datos es el proceso de **inspeccionar**, **limpiar** y **modelar datos** con el objetivo de **descubrir información útil**, **llegar a conclusiones** y apoyar la toma de decisiones.

* **Resultado:** Un informe, una gráfica
* **Objetivo:** Comprender el pasado y generar reportes para que la empresa (los humanos) pueda tomar decisiones en el presente y futuro.
* **Herramientas:** Excel, SQL, Tableau, Power BI, Python (Pandas)

**Clave**
* Obtener datos
* Explorar datos
* Hacer preguntas
* Encontrar respuestas

**Ejemplo Netflix:**

* ¿Qué tipos de series ve la gente?
* ¿Qué actores gustan más?
* ¿Qué género produce más dinero?
